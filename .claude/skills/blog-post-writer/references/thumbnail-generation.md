# 대표 썸네일 생성

새 글에 대표 이미지가 필요하거나 사용자가 요청했을 때 적용한다.

## 생성

1. 현재 환경의 이미지 생성 도구로 글의 핵심 구조나 문제 상황을 시각화한다.
2. 16:9 가로 구도와 작은 카드에서도 구분되는 중심 형태를 사용한다.
3. 제목, 코드, 숫자, 로고와 워터마크는 이미지에 넣지 않는다.
4. 내부 상품명과 식별자는 프롬프트에도 포함하지 않는다.
5. 생성 결과를 직접 열어 문자, 구도와 주제 일치 여부를 확인한다.

같은 시리즈는 색과 재질을 맞출 수 있지만 각 글의 중심 구조는 구분돼야 한다.

## 저장

최종 파일은 글과 같은 디렉터리의 `images/` 아래에 둔다.

```text
<글 디렉터리>/images/<글 파일명>-thumbnail.jpg
```

가능하면 JPEG 품질 85 안팎으로 변환한다. PNG를 유지해도 되지만 저장소 크기를 확인한다.

기존 frontmatter를 보존하면서 상대 경로를 추가한다.

```yaml
thumbnail: ./images/<글 파일명>-thumbnail.jpg
```

저장 후 다음 명령으로 파일 존재와 비율을 확인한다.

```bash
python3 .claude/skills/blog-post-writer/scripts/validate_thumbnail.py <글.md>
```

검증이 실패하면 잘못된 `thumbnail` 값을 남기지 않는다. 이미지 생성에 실패해도 글 자체는 완성할 수 있으며, 이 경우 블로그 기본 이미지를 사용한다.
