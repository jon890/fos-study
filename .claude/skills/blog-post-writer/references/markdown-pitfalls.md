# fos-blog 마크다운 제약

일반 한국어 표현은 프로젝트 지침의 공용 검사기가 담당한다. 여기에는 fos-blog 구현에서 확인한 제약만 둔다.

## H2 숫자를 직접 붙이지 않는다

fos-blog는 H2 앞에 CSS 카운터를 표시한다. 원문에 `## 1. 제목`처럼 숫자를 쓰면 번호가 겹친다.

```markdown
## 원인 분석
```

H3 이하와 본문 단계 번호는 자동 번호 대상이 아니다. 문맥상 필요하면 사용할 수 있다.

## 내부 링크

Markdown 파일 링크는 현재 파일을 기준으로 한 상대 경로로 쓴다. 표시 텍스트는 경로가 아니라 대상 글의 제목이나 섹션 이름을 사용한다.

앵커는 제목 변경과 렌더러의 slug 규칙에 영향을 받는다. 특정 섹션으로 연결했으면 HTML 미리보기나 실제 블로그 렌더러에서 이동을 확인한다.

## Frontmatter

기존 frontmatter에 키를 추가할 때 `tags`, `categories`, `thumbnail`, `series`와 `seriesOrder` 같은 다른 값을 보존한다. 닫는 `---` 뒤에 빈 줄을 두고 H1을 시작한다.

## 렌더 확인

Bold와 이탤릭의 괄호·따옴표 조합을 정규식으로 금지하지 않는다. fos-blog는 `remark-gfm` 파이프라인으로 이를 정상 렌더링한다.

Mermaid와 ASCII 도식 중에서는 관계를 더 명확하게 전달하는 형식을 선택한다. 특정 문자 존재만으로 오류를 판정하지 않는다.
