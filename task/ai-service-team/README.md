# NHN AI 서비스 개발 업무 기록

**회사**: NHN | **팀**: AI 서비스 개발팀 | **기간**: 2025.12–현재

AI 기능 개발부터 AI에 넣을 문서의 품질, 결과 평가와 운영 안정성까지 연결하는 백엔드 업무를 맡고 있다.
이 팀에서 내가 맡은 프로덕트와 업무를 아래에 묶었다.

## 담당 프로덕트와 역할

| 프로덕트 | 사용자에게 제공하는 기능 | 내 담당 범위 |
| --- | --- | --- |
| AI 돌봄 분석·평가 | 돌봄 상황의 근거를 탐색하고 분석 결과와 조치를 작성 | 분석 실행·실패 추적과 그래프 기반 평가의 개발·개선 담당 |
| AI 웹툰 제작 도구 | 웹소설을 바탕으로 단계별 검토·수정을 거쳐 웹툰 컷 생성 | 내부 MVP의 요구사항·설계·구현 검토와 생성 흐름 개발 |
| 문서 파싱 서비스 | PDF·이미지·오피스 문서를 AI가 읽을 Markdown으로 변환 | 파싱 품질 검증, 처리 성능과 리소스 안정화 |
| OCR API | 이미지의 글자를 인식하는 기능을 API로 제공 | 호출·접속 안정성, 배포 전환과 오류 관측·개선 |
| RAG 데이터 파이프라인 | 문서를 검색해 답변의 근거로 쓸 수 있도록 검색 데이터 준비 | 문서 수집·변환·벡터 색인과 재시작 가능한 배치 설계·구현 |

주요 기술은 Java·Spring Boot·Spring Batch, Python·FastAPI·docling, OpenSearch, Next.js·React다.
프로덕트별 기록에서는 기능 구현과 검증, 운영에서 확인한 문제를 함께 다룬다.

## OCR API

이미지 인식 모델을 호출하는 서비스에서 요청 실패를 관측하고, 접속과 배포 전환의 안정성을 개선했다.

| 2026.04–현재 | HTTP 200 응답 안의 오류 코드를 지표로 만들고 대시보드 개선 | [HTTP 200 응답 안의 OCR 오류를 운영 지표로 만들기](ocr-business-error-monitoring.md) |
| 2026.04–현재 | 배포·파드 증감·노드 교체의 연결 실패 대응과 호출자 커넥션 회복 | [OCR 오토스케일 전환의 connection 에러를 양쪽에서 막기](ocr-scale-connection-resilience.md) |
